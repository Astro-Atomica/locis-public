# How to use loc.is

Updated October 7, 2026 · Build 1

Use [loc.is](https://loc.is/) to find a place and share a link to a geographic area. The link carries the location; your accompanying text explains what the place means and how to get there.

## Find and check a place

1. Open loc.is and enter a place name, address, latitude/longitude pair, location code or location link in the search field.
2. Select the intended result. Check the map and selected rectangle against the place you meant.
3. Decide whether you want to share a wider area or a smaller meeting spot. A venue, its entrance and a nearby gathering place can be different locations.
4. Click the location name or cyan dot to open its location link, then copy the full URL.
5. Open the copied link and check the area again before sharing it.

A location page stays on its linked place even if the recipient is elsewhere. A search result's name does not establish that its rectangle matches the place's real boundary.

## Understand the selected area

A location code describes a rectangle. Successive tiers can select smaller areas within a parent rectangle. Choose enough detail for the task, using the map to check what the final code covers.

A smaller cell does not make an original GPS reading or place record more accurate. The rectangle is not a legal boundary, building footprint, exact entrance or proof that someone visited. Keep directions and geographic evidence alongside the link when they matter.

Named-place results can use source extents or estimates. The [place atlas](https://loc.is/s/boundaries.html) helps inspect those representations; the [short code lab](https://loc.is/s/shortcode-lab.html) explores code scale. Neither replaces authoritative boundary evidence.

## Share a link

Publish a complete HTTPS URL, rather than a bare code. For example, [this example area](https://loc.is/38MC3A) demonstrates a location link; it is not a recommendation for your meeting spot.

In a message or invitation, include the place name, meeting time and a visible landmark. For a profile or public post, choose an area you are comfortable disclosing. Anyone who receives the link can decode its area.

For several places, individually checked links are the clearest starting point. The website also demonstrates comma-separated area sets. Check the combined map before sharing a compound expression; an area set does not define a route, visit order or custom labels. Consult the current website guide before relying on experimental syntax.

## Share a QR code

1. Open the location page for the area you checked.
2. Download that location's QR code and place it in your invitation, sign or document.
3. Retain its white border and add a readable location link and directions alongside it.
4. Scan the finished printed proof and confirm that it opens the intended area.

The QR code reveals the same location as its link. A successful screen scan does not establish that the final printed size, paper and layout will scan correctly.

## Use your device location

The homepage can show an approximate location from your public IP. This can differ substantially from where you are. For a closer match, choose **Share device location for a more accurate map** and allow the browser's location request. Check the result before sharing it; permission does not guarantee measurement accuracy.

Read [privacy and safe sharing](privacy-and-sharing.md) before posting a personal location. If a result or control looks wrong, use [troubleshooting](troubleshooting.md) and the [reporting guide](reporting-issues.md).
