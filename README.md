The website guides describe the visitor-facing features. LOCIS remains an experiment: encoded rectangles, source geography and estimates of named areas are distinct. A location code or map is not proof of a property boundary, entrance or GPS accuracy.

## Report a problem

[Choose a report form](https://github.com/Astro-Atomica/locis-public/issues/new/choose) for a website bug, a place/location-data problem or a documentation correction. Search [existing reports](https://github.com/Astro-Atomica/locis-public/issues) first and follow the [reporting guide](docs/reporting-issues.md).

Issues and attachments are public. Use a harmless example location, and remove precise personal locations, credentials and private account information. Report security vulnerabilities or sensitive details through the [private contact guidance](SECURITY.md).

## Contributions and scope

See [CONTRIBUTING.md](CONTRIBUTING.md) for documentation contributions and [the support process](docs/support-process.md) for maintainer guidance.

`locis` is the project HQ and project brain; `locis-website` is the deployable website project. This repository owns the public docs and reporting surface, including the portable static documentation build. Static docs hosting and publication are separate decisions. SDK and widget source ownership remains open. Website implementation, website deployment tools, internal security findings and private review records belong in their owning projects. Opening or closing an issue does not establish that a fix has been deployed.
